## 3. 罠（R1 で間違えて、レビューで直った 5 点）

**同じ穴に落ちないこと。** どれも「そのまま実装すると誤る」形で見つかった。

1. **`SUM(a) * c` と `SUM(a * c)` は同値ではない。**（R2 §3.3 / §8.3）
   非数値のキーでは**外側 `NaN` / 内側 `0`**（内側は各行 `NaN` → 集計入力から除外 →
   空の `SUM` が `0`）。小数では binary64 の丸め位置も違う。
   **受入で「一致すること」を書かないこと。**整数の既知データだけ既知期待値で固定する。

2. **`ROLLUP` / `CUBE` / `GROUPING SETS` は拒否する。**（R2 §1.1）
   小計・総計行では除外キーが `""` に上書きされ、元行を読む SELECT 側と
   出力行を読む `HAVING` 側で値が食い違う。**専用診断を出して拒否**する。

3. **集計関数から始まる形だけを対象にする。**（R2 §1.2）
   `単価 * SUM(a)` / `@r * SUM(a)` / `(単価 + SUM(a))` は**拒否**。既存の入口は
   式が集計関数で始まるときだけ集計算術式の経路へ入るため、入口を変えると影響範囲が跳ね上がる。

4. **`AGG_VARIABLE` という新タグを作らない。既存の `VariableRef` を再利用する。**（R2 §4）
   既存の変数解決器・未解決変数 backstop・静的参照解析は `type === "VARIABLE"` だけを見ており、
   新タグでは値へ置換されず参照としても数えられない。**非数値は既存どおり `ArgumentError`**
   （`NaN` にしない）。

5. **`GROUP BY` キーの同一性は「表記一致」。**（R2 §3.2）
   `GROUP BY m.仕入価格` に対して `仕入価格` は**不可**。既存の名前解決は metadata-backed で、
   パース時の文字列だけでは同一性を確定できないため、意図的に狭くしてある。

### そのほか必ず守る点

- **evaluator は `row[node.field]` を直接読まず `resolveFieldRef` を使う**（R2 §6）。
  直接読むと修飾名の有無で SELECT と `HAVING` が食い違う
- **`evalAggArithExpr` / `evalMaterializedAggregateOperand` は
  「NUMBER でも AGG_REF でもなければ `AGG_ARITH`」と決め打ちしている。** 新 leaf で壊れる
- **`aggregateOperandLabel` の既存形のラベルを変えないこと。**
  合成キー名が変わると `HAVING` / `ORDER BY` の解決が壊れる（集計算術式 alias 消失バグと同じ経路）
- **`CaseResult` は `AggOperand` を含まない**（`AggregateRef | AggArithExpr`）。
  波及するのは `StringFuncArg` のみ
- **検証は `GROUP BY` を読み終えた後**に SELECT 全体（SELECT 列・`HAVING`・`CASE` 内・
  文字列関数引数）を走査して行う。**`WITH` / `UNION` / サブクエリは SELECT ごとに独立**に検証し、
  内側が外側の `GROUP BY` キーを参照できないようにする

## 4. 受入・回帰

R2 §8 のとおり。落とさないでほしいもの:

- **§8.1** 実データの既知期待値（在庫金額 8 製品・**合計 482,710**）
- **§8.2** 同じ式を SELECT・`HAVING` 直接・`HAVING` 別名の **3 経路**で書いて行集合が一致すること。
  **閾値は桁を変えて両方向で置く**（桁が揃うと文字列比較でも通り検出力が無い）
- **§8.3** 同値を主張しないケース（非数値 → 外側 `NaN` / 内側 `0` を**独立に**固定。
  小数は相対誤差。`@変数` の非数値は `ArgumentError`）
- **§8.4** 拒否 6 形（`GROUP BY` に無い / `GROUP BY` 無し / grouping sets /
  非集計始まり / 表記不一致 / 入れ子の外側キー参照）
- **§8.5** 回帰。とくに **alias 消失バグの回帰を全件**、**B119〜B122 の受入を全件**、
  **合成キー名が既存形で変わらないこと**
