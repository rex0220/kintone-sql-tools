# B209 変数の型を効かせ、数値と文字列の混在した大小比較を止める（fail-open の残り）

- 状態: ✅ **v3.93.0 で公開済み（2026-11-09）**＝npm latest 3.93.0・GitHub Release・公開した tarball で受入 20/20 OK（B208 と同じ版。**決定: 2026-11-09 Takashi「アを今回まとめてやる」**）
- 種別: 正しさ（**fail-open**）。**結果が変わる**
- 版: minor（v3.93.0）。**規模 S〜M**
- 見つけ方: B208 の実装レビュー（Codex。MAJOR）。B208 はサブクエリ側の来歴を直したが、
  **上限を変数で渡す形**が辞書順のまま残っていた
- 関連: [B208](ksql_b208_assert_scalar_field_numeric_issue.md)（同じ版）、B171（辞書順の fail-open を集計で直した）

## 1. 現象（B208 を入れても残っていた）

```sql
DECLARE @limit = 2;
ASSERT (SELECT COUNT(*) FROM APP200) <= @limit;   -- 件数 12 でも通っていた（fail-open）
```

`DECLARE` は**数値リテラルで書いても文字列として持つ**（注入された値も文字列）ので、
左辺（集計＝数値）と右辺（文字列）が混在し、B171 の規則で**辞書順**に落ちていた。
`"12" <= "2"` は真なので**件数ゲートが素通り**し、逆に上限 `'10000'` なら
`"12" > "10000"` で**止まるべきでないのに止まる**。

## 2. 直したこと

### 2-1. 数値リテラルで宣言した変数は「数値」として比べる

- `DECLARE @limit = 10000;` の既定値が **NUMBER リテラル**なら、その変数に数値の来歴の印を付ける。
- **注入された値も宣言の型で検証する**（`validateDeclaredBatchVariables`）。
  数値として読めない値は**レコードを 1 件も読む前**に `ArgumentError`
  （B203 の「宣言が種類を決める fail-closed」と同じ考え）。
- **値から型を推測しない**（B171 の方針そのまま）。見ているのは**宣言のリテラルの種類**と**注入の検証**。

**AST は変えていない。** 置換後も STRING ノードのままで、印は**ノードの同一性**（WeakSet）で持つ
（`countTotalCountRootSelects` と同じ仕組み）。理由は **`WHERE` の押し下げ・クエリの組み立て・書き込みの形を
1 つも変えない**ため（`WHERE 残数 > @limit` は今までどおり `残数 > "5"` を送る。試験でスナップショットに固定）。

### 2-2. 数値と文字列の混在した大小比較はエラー

`<` `<=` `>` `>=` `BETWEEN` で来歴が混ざったら、**辞書順に落とさずエラー**にする（fail-closed）。
文は「数値リテラル（`<= 10000`）か、数値リテラルで宣言した変数（`DECLARE @limit = 10000;`）を使ってください」と案内する。

**除外**: **空文字**（`''`）の比較。「値が無い」の比較には定義済みの規則（`WHERE` と同じ −∞ 扱い）があり、
辞書順でも同じ答えになるので今までの判定を保つ（`ASSERT '' < -1000000` は成立）。
**等値（`=` / `!=`）は対象外**（B171 のまま）。

## 3. 試験（`b208AssertScalarFieldNumeric.test.ts` に 10 件追加・計 21 件）

数値リテラルの宣言／注入した値（数値として読める文字列）／数値でない注入の拒否（レコード 0 件）／
文字列の宣言との混在の拒否／`BETWEEN` の混在の拒否／等値は不変／文字列どうしの辞書順は不変／
空文字の規則は不変／**`WHERE` の置換の形が変わっていないこと**（スナップショット）。

## 4. 影響（結果が変わる）

| 形 | v3.92.0 | v3.93.0 |
|---|---|---|
| `DECLARE @limit = 10000;` ＋ `<= @limit` | 辞書順（誤判定） | **数値** |
| `DECLARE @limit = '2';` ＋ `<= @limit` | 辞書順（`12 <= "2"` が真） | **エラー**（混在） |
| 数値の宣言に数値でない値を注入 | 実行まで進む | **実行前に `ArgumentError`** |
| 等値・文字列どうし・空文字 | — | **不変** |
| `WHERE` の変数の置換・押し下げ | — | **不変** |
