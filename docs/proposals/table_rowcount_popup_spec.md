# 結果表示: 行数クリックポップアップ仕様

## 目的
- 結果表示オプション `テーブル = 行数のみ` を維持しつつ、必要時にサブテーブル内容を確認できるようにする。

## 対象
- 画面: SQL実行結果テーブル（SELECT結果）
- 対象セル: `N 行` 形式で表示されるサブテーブル行数セル

## 基本仕様
- `N 行` の文字列をクリック可能にする（リンク風表示）。
- クリック時にモーダルポップアップを表示し、サブテーブルの中身を表示する。
- 多重クリックや再描画後でも、クリックイベントは重複登録しない（モーダル多重表示を防止）。
- モーダルは以下で閉じる:
  - `Esc`
  - モーダル外クリック
  - 閉じるボタン
- `閉じる` ボタンは 1 回クリックで確実に閉じる（`Esc` と同等の終了動作）。

## 表示内容
- サブテーブル行をテーブル形式で表示する。
- 列はサブテーブル内のフィールドコードを使用する。
- 左端に行番号列（`#`）を表示する。
- 表示上限:
  - 先頭100行まで表示
  - 101行目以降は省略メッセージを表示

## フィルター / 件数表示
- モーダル内にフィルター入力を表示する。
- フィルターは全列文字列に対する部分一致。
- 件数表示:
  - 未入力時: `N 件`
  - フィルター入力時: `表示件数 / 全件数`（例: `3 / 36`）

## 適用条件
- `テーブル表示オプション = 行数のみ` の場合に有効。
- `テーブル表示オプション = そのまま` では無効。
- `EXPLAIN` 結果では無効（通常SELECT結果のみ）。

## ソート
- 列ヘッダークリックで昇順/降順を切り替える。
- 数値文字列は数値として比較し、それ以外は文字列比較でソートする。
- 行番号列（`#`）はソート対象外。

## セキュリティ
- ポップアップ内の値はHTMLエスケープして表示する。
- 生HTML描画は行わない。

## UX仕様
- クリック可能セルは下線/ポインタで視認可能にする。
- モーダルサイズは画面内に収まる範囲（最大高さ・幅を指定）。
- モーダル内テーブルは縦横スクロール対応。

## エラー/例外
- 解析できないデータ形式の場合は「表示できません」メッセージを出す。
- データ0件の場合は「0件」表示。

## 実装メモ
- 推奨実装箇所:
  - `src/ui/renderResult.ts`（クリック可能HTML・data属性付与）
  - `src/ui/desktop.ts`（クリックイベント委譲・モーダル制御）
  - `prod/css/desktop.css`（リンク風セル・モーダルスタイル）
- data属性には必要最小限のJSONを保持し、サイズ肥大化に注意する。
