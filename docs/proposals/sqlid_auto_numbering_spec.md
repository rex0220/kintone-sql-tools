# SQLID 自動採番仕様（追加画面）

## 目的
- 追加画面で `SQLID` を自動採番し、手入力ミスを防止する。

## 対象項目
- `識別`（ドロップダウン）: `A`, `B`, `C` など
- `SQLID`（文字列）

## 採番ルール
- 追加時に `SQLID = 識別 + "-" + 連番` を採用する。
- 連番算出:
  1. `SQLID like "${識別}-"` で対象レコードを検索
  2. 数値部を抽出して最大値を取得
  3. `最大値 + 1` を採番
- 例:
  - 既存: `A-1, A-2, A-10`
  - 新規: `A-11`

## 実行タイミング
- 追加画面の保存時（`create.submit`）で最終採番する。
- 追加画面の表示時に仮表示する場合でも、保存時に再計算して確定する。

## 編集画面
- 編集画面では `SQLID` を編集禁止にする。
- 編集保存時に `SQLID` は変更しない。

## 競合対策
- 同時登録で重複が起きる可能性があるため、保存時に重複チェックを行う。
- 重複時は再採番して再試行（1～2回）する。

## 表示/入力仕様
- `識別` 未選択時は採番しない（保存エラーにするか、警告表示して保存中止）。
- 連番のゼロ埋めは任意（本仕様では未定義）。
  - 例: `A-1` または `A-001`

## エッジケース
- `SQLID` が規則外（例: `A-XYZ`）の既存データは、数値抽出できないため最大値計算から除外する。
- 識別値に `-` を含めない運用とする。

## 実装メモ
- 推奨イベント:
  - `app.record.create.submit`
  - `app.record.edit.show`（編集禁止制御）
- 推奨ヘルパー:
  - `generateSqlIdByPrefix(prefix: string): Promise<string>`
  - `parseSqlIdNumber(sqlId: string, prefix: string): number | null`
