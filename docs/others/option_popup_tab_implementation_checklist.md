- [ ] `表示 / 取得 / 保存SQL / フィールド` の4タブを実装

## 3. 機能移設
- [ ] 表示オプション（ユーザー/配列/テーブル/日時）を `表示` タブへ移設
- [ ] 取得オプション（最大取得件数/上限到達時の動作）を `取得` タブへ移設

- [ ] フィールド一覧を `フィールド` タブへ移設

## 4. 画面別反映ルール
- [ ] 追加画面: 変更は即時表示、保存時に `event.record` へ反映

- [ ] 実行時に `上限到達時の動作` の最新値を使用
